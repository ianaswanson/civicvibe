The process

Eight steps in four stages. It runs as a loop, not a line.

Define

1. Capture ideas

2. Set direction

3. Plan the quarter

Discover

4. Discover: research, choose, test

Deliver

5. Slice the work

6. Build and release

7. Review the sprint

Enable

8. Enable: launch, train, measure, feed back

The earlier version showed Discover, Define, Design, Deliver and Enable, adapted from 18F. The system now uses eight steps; the four stages are only labels for grouping them. Discovery happens inside each piece of roadmap work, not once at the start.
