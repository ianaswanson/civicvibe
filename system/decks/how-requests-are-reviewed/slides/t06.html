Bugs skip triage

A bug is something we built that doesn't work as intended. Nobody is asking for a change.

Bug reported

→

Technical architect

→

Stops people using the service, exposes data, or opens a security hole

→

Fix it now

Everything else

→

Technical maintenance list, in priority order

It counts as Technical maintenance

Bugs are paid for from Technical maintenance time, not small request time, whoever reported them.

Unless it isn't a bug

If a "bug" is really a request for different behavior, send it back to triage.

DMV example: "Renewal payments over $500 fail at the last step." It blocks people from finishing, so the technical architect had it fixed that day.
