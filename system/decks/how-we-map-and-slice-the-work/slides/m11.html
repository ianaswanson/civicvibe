A release is a vertical slice

In our system, each release slice scheduled into a quarter is a Deliverable.

Horizontal: a phase

Database this quarter, screens next quarter. Nobody can use it, so nobody can tell us if it's right.

Vertical: a slice

A thin path through every layer that works end to end for someone. We can demo it to a real user and learn.

The test

Can you demo it to a real user and get useful feedback? If not, it's a horizontal piece.

Learning slices

Some slices test the riskiest assumption with real users, often by hand or behind a flag, before we build the rest.

From doc 11. A Deliverable someone can't use is a phase, not a slice. A vertical-versus-horizontal slices picture would do the job of the two top cards.
