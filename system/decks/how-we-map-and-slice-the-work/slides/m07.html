The "So that what?" test

Ask: the person does this... so that what?

"So they can click another button"

Or "so they can see something." It's interaction-focused. Rewrite it.

A meaningful outcome or capability

It's outcome-focused. Keep it.

It also sizes a detail

A detail is the right size when it reads as "As a [user], I want [action], so that [benefit]," and splitting it further gives pieces with the same "so that."

"Log in with Google" is one detail, not "enter email," "click button" and "redirect." All three serve the same benefit: so that I don't have to create and remember another login.

This is the test the system uses for stories too: if two pieces share the same "so that," they were one story.
