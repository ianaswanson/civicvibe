Two competing systems

Projects

One system provides "project" work and has its own specific process with roles and responsibilities.

Operations

Another system is managed by different people with different processes, roles and responsibilities.

The challenge

People are caught in between these two systems, and have no way to reconcile them.

Software used to come in a box. Today it is continuous, with no finish line. We still fund it, build it and "operationalize" it, so people get caught between a project system and an operations system.
