Where the gaps were

A scrum gap analysis from a team that went through this before us.

Pre-sprint

  • Alignment document: epic definition and scope
  • Quarterly release goal planning
  • User story mapping
  • Release slicing
  • Story vertical slicing (INVEST)

Sprint

  • Definition of done
  • Definition of ready
  • Sprint goals
  • Budgets
  • Multiple boards, one team
  • Estimation gap
  • Spike usage

Post-sprint

  • New feature release notes

Most gaps were not about effort. They were about agreements nobody had written down: when a story is ready, when it is done, what the sprint is for.

This is that team's scrum gap analysis, word for word. Run the same exercise with your team. The pre-sprint gaps are covered in the planning and story mapping decks; this deck covers the sprint and post-sprint columns.
