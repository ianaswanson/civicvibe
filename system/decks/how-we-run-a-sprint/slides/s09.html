One story, three versions

Version 1

Not ready

"As a customer, I want to be able to pay with credit cards so that I can purchase products online."

  • Very vague: which cards? which payment process?
  • Too broad: might take several sprints
  • No acceptance criteria to test against

Version 2

Better, but not ready

"As a customer, I want to be able to pay using Visa or Mastercard credit cards, so that I can conveniently purchase products."

  • More focused, but may depend on existing payment setup
  • Smaller, but might still be large
  • Testable only in part: no criteria for errors

Version 3

Ready

"As a customer shopping online, I want to pay using Visa or Mastercard, credit or debit, so that I have flexible payment options." Integrates with existing checkout; supports international cards.

  • Can be built and released on its own
  • Fits in a sprint, with backend in place
  • Clear criteria: success, failure, card types, international
From the earlier team's Q1 2024 planning deck, trimmed to the key INVEST points for each version. Walk left to right and ask the room which letter each version fails.
