# Deliverable

A tangible thing handed over, so a commitment can be checked as met or not. On the roadmap, a Deliverable is a slice of a Solution committed for this quarter.

- **Definition:** [Glossary: Deliverable](../00-glossary.md)
- **How it works:** [11 Deliverables and user stories](../11-deliverables-and-user-stories.md)
- **Owner:** product manager schedules; product owner runs delivery
- **Links to:** Parent: [Solution](solution.md). Children: [User story](user-story.md), [Release notes](release-notes.md). Stories may also be grouped in [epics](epic.md)

## Template

| Field | What goes here |
| --- | --- |
| Deliverable | Short name |
| Solution | Parent Solution, linked |
| Initiative | The Initiative the Solution belongs to |
| Quarter | When it's committed |
| Target date | When it will be delivered. Matches the date on the roadmap's intended progress card |
| Delivery type | Release, In service or Hand off |
| Target outcome | What people will be able to do when it's delivered |
| In the slice | Story map details included |
| Epics | Optional. Any epics the team uses for this work, linked |
| Size | XS, S, M or L. An XL must be sliced further |
| Dependencies | Other teams, contracts, reviews |
| Status | Committed, On track, Off track, Done |

## DMV example

**Deliverable: Pre-check for birth certificates and proof of address**

| Field | Entry |
| --- | --- |
| Deliverable | Pre-check for birth certificates and proof of address |
| Solution | License Ready Check |
| Initiative | Single-trip new driver licenses |
| Quarter | Q3 (Now) |
| Target date | Sep 26, end of Sprint 6 |
| Delivery type | Release |
| Target outcome | First-time applicants learn before their visit whether their birth certificate and proof of Oregon address will be accepted. |
| In the slice | Know which documents count. Compare against examples of accepted birth certificates. Submit a birth certificate photo. Submit proof of address. Staff review queue. Know whether it was accepted, and what to bring instead. Clerk sees the pre-check result at the counter. Gather documents and Book visit: nothing new. |
| Epics | Birth certificate check (S). Proof of address check (S). |
| Size | M |
| Dependencies | Digital Identity Verification intake queue. Legal review of document storage. Reviewer training (of Staff workflow redesign). |
| Status | Committed |
