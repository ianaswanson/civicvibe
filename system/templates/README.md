# Templates

One file per artifact. Each has a blank template and a filled DMV example. Definitions live in the [Glossary](../00-glossary.md); how each artifact is used lives in the numbered documents.

| Artifact | Changes | Template |
|---|---|---|
| Roadmap | Quarterly; sprint report each sprint | [roadmap.md](roadmap.md) |

| Idea | Ongoing | [idea.md](idea.md) |
| Small request | Ongoing | [small-request.md](small-request.md) |
| Initiative | Open until the outcome is reached | [initiative.md](initiative.md) |
| Solution | As tried, kept or dropped | [solution.md](solution.md) |
| Discovery brief | Each round of discovery | [discovery-brief.md](discovery-brief.md) |
| Assumption log | During discovery | [assumption-log.md](assumption-log.md) |
| Deliverable | Committed quarterly | [deliverable.md](deliverable.md) |
| Epic (optional) | As the team needs | [epic.md](epic.md) |
| User story | Each sprint | [user-story.md](user-story.md) |
| Sprint report | Each sprint | [sprint-report.md](sprint-report.md) |
| Release notes | Each release | [release-notes.md](release-notes.md) |
| Launch readiness check | Each launch | [launch-readiness-check.md](launch-readiness-check.md) |
| Enable plan | Each launch | [enable-plan.md](enable-plan.md) |
